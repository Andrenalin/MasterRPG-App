"Dice are the heart of every game. This editor manages the dice and special rules for how a result is calculated.\n\nCategories: rule dice belong to a rule system, table dice are for the tables module (usually summed), and character dice are special dice used inside a character.\n\nSettings\nSum dice: add up all dice, exploding dice included.\nModifier: always added to (or subtracted from) the roll.\nCheck against: compare the result with a value (less than, less or equal, greater or equal, greater), or switch it off.\n\nCritical hit and fumble settings\nChoose whether a single die value or the total triggers it, enter the number and add it. A critical hit is a lucky success, a fumble a total failure. Optionally only the first die counts.\n\nReroll settings\nA die can be rolled again (an exploding die). Either only the new roll counts, or all rolls are added, with an optional replacement value for the first roll.\n\nSpecial settings\nSort dice by value before calculating (DungeonSlayers), or add another die at a threshold, for example another D20 on every 20.\n\nA character value can link a dice and use its own number as the comparison value. The Battle Round rolls the dice linked to the Ini entry for the initiative."
